# Prism

Personal finance tracker – **phone preview build**.

`index.html` is a single self-contained file (HTML, CSS and JavaScript inline, no build step).
Open it in any browser; data is stored in that browser's `localStorage`.
It starts with sample data (Settings → *Mintaadatok* resets it).

## Publish with GitHub Pages

1. On GitHub (in a browser): **Settings → Pages**.
2. *Source*: **Deploy from a branch**, pick the branch that has `index.html` and the **/ (root)** folder, then **Save**.
3. After about a minute the page is live at `https://<username>.github.io/<repo>/`.

Free GitHub accounts can only publish Pages from **public** repositories.

Icons: [Lucide](https://lucide.dev) (ISC license). Exchange rates: European Central Bank via the [Frankfurter API](https://frankfurter.dev).
